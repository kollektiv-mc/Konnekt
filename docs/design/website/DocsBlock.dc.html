DH Snapshot

Warns the players, stops the server, copies the Distant Horizons databases out, and starts it again.

04

Errors

Message says
Do
config/DistantHorizons.toml was not found
Start the server once with DH installed.
serverId is not set
DH writes it on the first save of its config. Start the server once.
no Distant Horizons jar found in mods/
DH runs as a mod; the version is read from the jar.
neither RCON nor the server's console can carry the warning
Enable RCON, or set the lead time to 0.
