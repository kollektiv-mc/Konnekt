Publish Distant Horizons LODs

Copy the server's LOD data once a week, upload it to a bucket, and give players a link. A new player then starts with the whole world rendered in the distance.

DURATION~20 min
REQUIREMENTSDistant Horizons · R2 bucket · RCON
TOPICSDestinations · Scheduler · Distant Horizons
00

Before you start

The server runs Distant HorizonsIts jar is in mods/, and the server has started with it once, so config/DistantHorizons.toml exists.
serverKey and levelKeyPrefix are setBoth are empty by default and the snapshot refuses to run until they are. Edit the file while the server is stopped.
RCON is onenable-rcon=true and an rcon.password in server.properties, so players hear the warning.
There is free disk spaceThe databases' total size plus 1 GiB, on the volume Konnekt stages to.
01

Save the bucket

In Settings, open Destinations and add one.
Test it, then Save.

02

Build the graph

Open the Scheduler tile, start a new graph, and add four blocks.
Wire each block's onComplete to the next one's trigger.
Then wire the snapshot's Staged folder into the publish block.

Cron Schedule0 4 * * 0
DH Snapshotstops the server
Publish DH Snapshotkeep 3
Notifyinfo
Block
Field
Set it to
Cron Schedule
Cron expression
0 4 * * 0, every Sunday at 04:00, local time.
DH Snapshot
Warn players this many seconds before
300. At most 1800.
Publish DH Snapshot
Destination
The bucket you saved in step 1.
03

Run it once

Press save, switch the graph [on], then run to take the first snapshot now rather than on Sunday.
The snapshot's lines appear in the Console tile, and the first warning reaches chat at once.

HEADS UPThe server stops for the copy. A first snapshot copies everything; later ones copy only what changed.
04

When a run refuses

Message says
Do
serverKey is empty
Set it in config/DistantHorizons.toml, with the server stopped.
the server is not running
The block stops and restarts a running server. Start it first.
not enough free space to stage the snapshot
Free space, or point the staging folder at another volume.
