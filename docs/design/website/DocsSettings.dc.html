Remote Access

Serve the dashboard to a browser you have approved, reach it from outside your network, and let Claude in. Everything here is off until you switch it on.

Access

SETTING
WHAT IT DOES
DEFAULT
Remote access
Serves the dashboard to approved browsers. Turns off after 30 idle minutes.
Off · needs a password
Password
What a browser signs in with. Changing it signs every device out.
None · 12+ characters
Approved devices
Browsers that signed in and were approved here, on the desktop. Remove one to sign it out.
None
NOTEA new browser waits at sign-in until you approve it on this computer.

Reach it from anywhere

SETTING
WHAT IT DOES
DEFAULT
Tunnel
A Cloudflare tunnel to the dashboard, with a QR code for a phone. Without your own address, the address changes every time.
Off
Hostname
Your own address, routed in the Cloudflare dashboard to the port below.
None
Port
The local port remote access listens on when a named tunnel is set.
Tunnel token
The token Cloudflare gives the named tunnel. Stored on this computer, never shown again.
None

Lets claude.ai, Claude Desktop and Claude Code reach Konnekt through your own address. Each signs in with the password and your approval here.
