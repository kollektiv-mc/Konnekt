Getting started

What Konnekt needs, where it runs, and how to point it at your first server.

Requirements Platform support First server Build from source FAQ Fair warning

Requirements

Konnekt ships as a single native binary, with no runtime to install alongside it.

  • A Minecraft server you already have. Konnekt manages an existing server directory and jar; it doesn't download one.
  • Java. Required by the server, not by Konnekt.
  • RCON enabled in server.properties for the player list, kick/ban and commands. Console streaming works without it.
  • 64-bit Windows or Linux.

Platform support

Platform Build Status
Windows (x86-64) konnekt-windows-amd64.exe Published
Linux (x86-64) konnekt-linux-amd64 Published
Fedora / RHEL (x86-64) .x86_64.rpm Published
macOS Build from source Not published

Linux builds link against webkit2gtk-4.1, covering Rocky/RHEL 10, Fedora 36+, Ubuntu 22.04+ and Debian 12+. At runtime they need webkit2gtk4.1 and gtk3.

Rocky/RHEL 9 is not supported. EL9 never received webkit2gtk-4.1 and EL10 dropped 4.0; the two aren't binary-compatible.

macOS isn't published as a release yet, but builds from source with wails build.

Your first server

  1. Add a server. Point Konnekt at the jar, working directory and JVM arguments.
  2. Accept the EULA. First-time setup walks you through it.
  3. Start it. The console streams the log live and takes commands inline.
  4. Arrange the dashboard. Drag, resize and snap tiles, then save the layout as a preset.

You can add as many servers as you like and start, stop and restart each one. Switching the active server is incomplete in alpha: the worlds and mods tiles follow your selection, but the console, scheduler and status do not yet.

Build from source

Requires Go, Node.js with pnpm, and the Wails CLI. On Linux you also need the webkit2gtk and gtk3 development packages. 

git clone https://github.com/kollektiv-mc/Konnekt
cd Konnekt
pnpm install
wails dev

Run wails doctor first; it reports what your distro is missing. If WebKit detection fails, add the build tag: 

wails build -tags webkit2_41
wails dev -tags webkit2_41

FAQ

Is it free?

Yes. Released under CC0, so there's no copyright to ask permission from. No accounts, no tiers, no subscriptions.

Does it phone home?

No telemetry, analytics or crash reporting. Konnekt reaches the network in three cases: GitHub for update checks, Modrinth for mods, and your own server over RCON.

Which server types work?

Vanilla, Paper/Spigot/Bukkit, and modded Fabric, Forge and NeoForge. The loader is detected automatically. Bedrock isn't supported.

Where does it store my data?

Your server files stay where they are. Konnekt's own state (servers, layouts, presets, scheduled tasks) is JSON in the OS application-data directory.

Is it stable?

It's alpha. The core is functional and in daily use, but expect rough edges. See the roadmap.

Can I manage a server on another machine?

No. Konnekt manages servers on the machine it runs on. Web access is a later roadmap item.

Fair warning

This is a personal side project which was built to run my own Minecraft servers the way I want, rather than to match what a wider community might expect from it. Most of the code comes from Claude, with me reading over its shoulder rather than writing it myself; I'm not a programmer, just someone putting AI tools to use for something I needed. So don't expect a polished, textbook-clean codebase. It works for me, and that's the bar I'm holding it to.

I have no interest in gatekeeping any of this, so take the code and do what you want with it — fork it, extend it, rebuild it, whatever. It's released under CC0, so there's no copyright to ask permission from.
