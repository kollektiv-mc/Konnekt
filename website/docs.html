Getting started

What Konnekt needs, where it runs, and how to point it at your first server.

Requirements Platform support First server Build from source FAQ Fair warning

Requirements

Konnekt ships as a single native binary. There is no runtime to install alongside it — no Java, no Node, no Electron bundle.

  • A Minecraft server you already have. Konnekt manages an existing server directory and jar; it does not download or provision one for you.
  • Java — required by the server, not by Konnekt. Whatever version your server jar needs is what you need installed.
  • RCON enabled in server.properties if you want the player list, kick/ban and command features. Console streaming works without it.
  • 64-bit Windows or Linux — see below.

Platform support

Platform Build Status
Windows (x86-64) konnekt-windows-amd64.exe Published
Linux (x86-64) konnekt-linux-amd64 Published
Fedora / RHEL (x86-64) .x86_64.rpm Published
macOS Build from source Not published

Linux builds link against webkit2gtk-4.1, which covers Rocky/RHEL 10, Fedora 36+, Ubuntu 22.04+ and Debian 12+. At runtime they need webkit2gtk4.1 and gtk3.

Rocky / RHEL 9 is not supported. EL9 never received webkit2gtk-4.1 and EL10 dropped 4.0, and the two are not binary-compatible — so there is no build that can satisfy both. This is a hard limit, not a gap waiting to be filled.

macOS runs fine as a native app but is not published as a release yet; build it with wails build like any other platform.

Your first server

  1. Add a server. Point Konnekt at the jar, set the working directory, and set the JVM arguments you want (heap size, flags).
  2. Accept the EULA. First-time setup walks you through it rather than failing silently on a missing eula.txt.
  3. Start it. The console tile streams the log live and takes commands inline.
  4. Arrange the dashboard. Drag, resize and snap tiles, crate the ones you don't want, and save the arrangement as a preset.

Add as many servers as you like — each one starts, stops and restarts independently.

Build from source

Requires Go, Node.js with pnpm, and the Wails CLI. On Linux you also need the webkit2gtk and gtk3 development packages. 

git clone https://github.com/kollektiv-mc/Konnekt
cd Konnekt
pnpm install
wails dev

Run wails doctor first — it reports exactly what your distro is missing. If WebKit detection fails on a webkit2gtk-4.1 system, add the build tag: 

wails build -tags webkit2_41
wails dev -tags webkit2_41

FAQ

Is it free?

Yes, and more than free — it's released under CC0, so there is no copyright to ask permission from. Fork it, extend it, rebuild it, ship it. No accounts, no tiers, no subscriptions — those are explicitly out of scope.

Does it phone home?

No. There is no telemetry, no analytics and no crash reporting. Konnekt makes network requests in exactly three cases: to GitHub when it checks for a new release, to Modrinth while you browse or install mods, and to your own server over RCON.

Which server types work?

Vanilla, Paper/Spigot/Bukkit, and modded Fabric, Forge and NeoForge. Konnekt detects the loader automatically when resolving mods. Bedrock Edition is out of scope — the command syntax is different enough that it would be a separate product.

Where does it store my data?

Your server files stay exactly where they are — Konnekt reads and writes them in place. Its own state (server definitions, tile layouts, presets, scheduled tasks) is plain JSON in the OS application-data directory. Nothing is kept in a cloud account, because there is no account.

Is it stable?

It's alpha. The core — multi-server management, console, stats, players, scheduling, worlds, backups, config editing and mods — is functional and in daily use by its author. Expect rough edges, and see the roadmap for what's still moving.

Can I manage a server on another machine?

Not yet. Konnekt is a local-first desktop app and manages servers on the machine it runs on. A full dashboard over the web is on the roadmap as a later item, not an alpha or beta one.
