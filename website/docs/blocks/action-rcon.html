RCON Command

Sends a command over RCON and returns the server's reply.

Category
Action
Topics
Scheduler · RCON
01

Ports

RCON Commandaction
  • in
  • triggercontrol
  • Commandstring
  • out
  • onCompletecontrol
  • onFailedcontrol
  • Responsestring
Ports Control Data
Data types string number bool

Strings accept any data input.
Numbers accept boolean input.

02

Fields

Field What it does Default Limits
Command The command to send over RCON. None
  • Save All
  • Freeze Time
  • Set Day
  • Set Night
03

What a run does

A wired Command outranks the field.
It connects to the server's RCON port, logs in, sends the command and closes the connection.
Each run opens a new connection.

onComplete carries the reply in Response, with colour codes removed and spaces trimmed.
The reply can be empty.
Any error leaves by onFailed.

The address and password are the ones server.properties held when the server last started.
They count only if enable-rcon was true and rcon.password was set.
Its presets match the console presets of the Command block.

04

Errors

Message says Do
command is empty Fill in Command, or wire a value into it.
RCON not enabled or not running Set enable-rcon and rcon.password in server.properties, then start the server.
rcon dial: reason Check that the server is running and that rcon.port is right.
rcon auth: wrong password Check rcon.password in server.properties, then restart the server.
