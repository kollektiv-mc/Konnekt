Scheduler blocks

The blocks a scheduler graph is built from.

Topics
Scheduler

Trigger

BackupStarts a run when a backup finishes or fails. Cron ScheduleStarts a run whenever the clock matches a cron expression. IntervalStarts a run every set number of minutes. PlayerStarts a run when a player joins or leaves the server. ServerStarts a run when the server starts, stops or crashes. Time of DayStarts a run once a day at a set time. TPS Below ThresholdStarts a run when the server's TPS falls below a threshold.

Data

ConstantOutputs a fixed value of a chosen type. MathOutputs the result of arithmetic on two numbers. Random NumberOutputs a random number between Min and Max. Read AttributeOutputs the live value of a server attribute, or of a custom attribute set earlier in the run. Write AttributeWrites a server attribute such as server.motd, or defines a custom attribute for the blocks after it.

Action

Create BackupZips the whole server, or only its active world, into a backup archive. CommandSends a line to the server console, or starts, stops or restarts the server. DelayWaits a set number of seconds, then continues. HTTP RequestSends an HTTP request to a URL and outputs the status and the response body. RCON CommandSends a command over RCON and returns the server's reply. Upload to BucketUploads a file or folder from the server to a bucket, skipping what is already there. Publish DH SnapshotUploads a staged Distant Horizons snapshot to a bucket and publishes its download page. DH SnapshotStages a snapshot of the server's Distant Horizons data, stopping a running server for the copy.

Control

ConditionBranches on a comparison of A and B, or on a logic gate over the two.

Notify

NotifyShows a message in the app, as a desktop notification, or both.
