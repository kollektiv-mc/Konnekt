Player

Starts a run when a player joins or leaves the server.

Category
Trigger

Field What it does Default Limits
Type Whether the block fires when a player joins or when one leaves. Joined
  • Joined

Cooldown (seconds) The shortest time between two firings of this block, all players together. 300 0 s or more. A negative or empty value uses 300 s.
03

What a run does

Konnekt reads the console of a server it started.
Joined fires when a player joins, and Left when one leaves.
The run starts at this block and leaves by onComplete.

Player name carries the player's name.
Player IP carries the address on Joined and is empty on Left.
It can also be empty on Joined, when the server logs the address after the join message.

The cooldown counts per block, not per player.
A player who joins inside the cooldown does not start a run.
A value wired into Cooldown is not read.
It fires only for the server the graph belongs to.
