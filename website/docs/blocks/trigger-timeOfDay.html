Time of Day

Starts a run once a day at a set time.

Category
Trigger
Topics
Scheduler
01

Ports

Time of Daytrigger
  • in
  • Timestring
  • out
  • onCompletecontrol
Ports Control Data
Data types string number bool

Strings accept any data input.
Numbers accept boolean input.

02

Fields

Field What it does Default Limits
Time (HH:MM) The time of day to fire, on the computer's 24-hour clock. 00:00 00:00 to 23:59. A time that does not parse never fires.
03

What a run does

Once a minute, Konnekt compares the computer's clock with the Time (HH:MM) field.
When the hour and minute match, the block fires and the run leaves by onComplete.
It fires at most once per calendar day.

Konnekt must be running at that minute.
A missed time is not made up.
A value wired into Time is not read.

The run acts on the server the graph belongs to.
