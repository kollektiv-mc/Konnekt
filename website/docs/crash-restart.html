Restart after a crash

Start the server again each time it crashes.

Duration
~3 min
Requirements
A server · An open Konnekt
Topics
Scheduler
00

Before you start

  • Konnekt left openGraphs run only while Konnekt is open.
  • The scheduler editorMaximize the Scheduler tile to open it.
01

Add the trigger

Open the editor and select Open blocks, then Server.

Field Set to
Type Crashed
Cooldown (seconds) 300

Crashed does not fire when you press Stop, which counts as Stopped.
A crash inside the cooldown does not restart the server.
That keeps a server that crashes on boot from restarting in a loop.
What counts as a crash is on the Server block page.

02

Add the restart

Add Command.

Field Set to
Command Restart Server

Drag from onComplete on Server to trigger on Command.
On a stopped server, Restart Server only starts it, which is the state after a crash.

03

Switch it on

  1. Select Graph actions, then Save.
  2. Select [off] so it reads [on].

run restarts the server at once, crash or not.
A new graph starts off, and nothing fires until it is on.
