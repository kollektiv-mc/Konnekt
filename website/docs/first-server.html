Your first server

Point Konnekt at a server you already have, start it, and join it from Minecraft.

Duration
~10 min
Requirements
A server jar · Java
Topics
Servers · Console
00

Before you start

  • A server jarThe Minecraft server you already run. Konnekt manages it, it does not fetch one.
  • JavaYour server needs it to run. Konnekt itself does not.
  • RCON on in server.propertiesThe player list and commands need enable-rcon until Konnekt sets it up for you.
01

Add a server

Point it at the jar and the folder it lives in.
Then name it and give it RAM.

Servers
Survival
server.jar…
/home/mc/survival…
-Xms1G -Xmx4G
Add server
02

Install a server

Only for a Forge or NeoForge installer rather than a server jar.
Hand it the installer and it runs the install for you.
Then it adds what comes out.

[i]Installer detected
/home/mc/forge…
Running installer… Extracting libraries Downloading server
Install server Add server Close
03

Start it

Press Start.
The console streams the log live and takes commands inline.

STOPPED STARTING RUNNING Start Stop
Starting minecraft server 1.21 Loading properties Preparing level "world" Done (6.129s)! For help, type "help"
Heads up

A server that stops on its first run is almost always waiting for its EULA. Konnekt offers to write eula.txt for you, then starts it again.

04

Join it

The server runs on the machine you are sitting at, so its address is localhost.
In Minecraft, open Multiplayer, then Direct Connection.
Enter localhost as the Server Address, then Join Server.
