Install Konnekt

Konnekt is one file, with no runtime to install beside it.

Duration
~5 min
Requirements
Windows or Linux, 64-bit
Topics
Download · Platforms
00

Before you start

  • A 64-bit Windows or Linux machinemacOS has no published build, and builds from source below.
  • The machine your server runs onKonnekt manages servers on the machine it runs on.
01

Download

Open the download page and take the file for your system.

Platform File
Windows konnekt-windows-amd64.exe
Linux konnekt-linux-amd64
Fedora, Rocky and RHEL 10 konnekt-<version>.x86_64.rpm
See also

Which build is a release and which only a snapshot: Requirements and platforms.

02

Windows

Run konnekt-windows-amd64.exe.
There is nothing to install, so keep the file where you want it to live.

Heads up

Windows builds are not code signed yet, so a first launch shows a SmartScreen warning. Choose More info, then Run anyway.

03

Linux

Konnekt needs webkit2gtk4.1 and gtk3 at runtime.
Fedora 36, Ubuntu 22.04, Debian 12, Rocky and RHEL 10, and anything newer have both.
Make the file executable, then run it. 

chmod +x konnekt-linux-amd64
./konnekt-linux-amd64

On Fedora, Rocky or RHEL 10, the package pulls in both libraries and adds Konnekt to your applications. 

sudo dnf install ./konnekt-*.x86_64.rpm
Heads up

Rocky and RHEL 9 are not compatible.

04

Build from source

A source build is the newest code, so it is a snapshot: newer than the release, and untested.
It needs Go, Node.js with pnpm, and the Wails CLI.
On Linux it also needs the webkit2gtk and gtk3 development packages. 

git clone https://github.com/kollektiv-mc/Konnekt
cd Konnekt
pnpm install
wails dev

Run wails doctor first: it reports what your system is missing.
If WebKit detection fails, add the build tag. 

wails build -tags webkit2_41
wails dev -tags webkit2_41
05

Check the download

Every release file carries a signed build provenance attestation and a checksum.
The commands to check either are on the download page.

Verify your download.
