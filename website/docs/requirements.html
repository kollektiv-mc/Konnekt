Requirements and platforms

Konnekt is one file, with no runtime to install beside it.

Topics
Platforms · Java · Server jars
01

Requirements

Requirement Why
A server jar The Minecraft server you already run. Konnekt manages it, it does not fetch one.
Java Your server needs it to run. Konnekt itself does not.
Windows or Linux, 64-bit macOS builds from source today.
02

Platform support

Platform Build Status
Windows (x86-64) konnekt-windows-amd64.exe ALPHA
Linux (x86-64) konnekt-linux-amd64 ALPHA
Fedora, Rocky and RHEL 10 (x86-64) .x86_64.rpm ALPHA
macOS Build from source SOURCE
  • Rocky and RHEL 9 are not compatible.
  • Linux needs webkit2gtk4.1 and gtk3 at runtime: Fedora 36, Ubuntu 22.04, Debian 12, Rocky and RHEL 10, and anything newer.
  • macOS has no published build, and builds from source.
03

Server types

Vanilla, Paper, Spigot and Bukkit, and modded Fabric, Forge and NeoForge.
The loader is detected automatically.
Bedrock is not supported.
