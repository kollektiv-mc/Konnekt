Warn, then restart every 6 hours

Tell players a restart is coming, then restart the server every 6 hours.

Duration
~8 min
Requirements
A running server · An open Konnekt
Topics
Scheduler · Console
00

Before you start

  • Konnekt left openGraphs run only while Konnekt is open. The 6-hour timer lives in memory, so closing Konnekt resets it.
  • The scheduler editorMaximize the Scheduler tile to open it.
01

Add the trigger

Open the editor and select Open blocks, then Interval.

Field Set to
Interval (minutes) 360

The first check that sees the graph on starts the timer.
The first restart comes 6 hours after that.
For fixed times, use Cron Schedule with 0 */6 * * * instead.

02

Warn the players

Add two Command blocks and two Delay blocks.
Wire them in table order, each onComplete to the next block's trigger.
Start from onComplete on Interval.

Block Field Set to
Command Command say The server restarts in 1 minute.
Delay Seconds 50
Command Command say The server restarts in 10 seconds.
Delay Seconds 10

One Delay waits 60 seconds at most, and a longer wait fails.
For an earlier warning, chain more Delay blocks.

03

Add the restart

Add a third Command.

Field Set to
Command Restart Server

Drag from onComplete on the last Delay to trigger on the new Command.
It stops the server, waits for it to exit, and starts it again.

Heads up

The editor may warn that RCON is not confirmed for this block.
The say lines already warn players through the console.
A warning does not stop the graph from saving or running.

04

Switch it on

  1. Select Graph actions, then Save.
  2. Select [off] so it reads [on].

run starts the graph at once: the warnings go out, and the server restarts a minute later.
A new graph starts off, and nothing fires until it is on.
