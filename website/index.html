01

Features

Open the demo →

Tile dashboard

01 / 09

  • Drag, resize and snap

    Pick a tile up by its title bar and the grid makes room.

  • Crate what you do not use

    A closed tile waits in the sidebar until you want it back.

  • Layout presets

    Console focus, compact, essentials, or your own.

Live console

02 / 09

  • Live log streaming

    The log as the server writes it.

  • Send commands inline

    Type at the prompt and the reply lands in the same stream.

  • Filter and search

    Narrow the scrollback to one kind of line, or to a word.

Players

03 / 09

  • See who is online

    A card per player, lit while they are on.

  • Kick or ban with a reason

    The reason goes with the command.

  • Op, whitelist and bans

    Each player’s standing, in one panel.

Performance

04 / 09

  • Live TPS, CPU and memory

    Read off the process and the tick.

  • An hour of history

    A sample every ten seconds, kept for an hour.

  • No plugins to install

    The server never knows it is watched.

Worlds

05 / 09

  • Each world as a planet

    Its nether and end as moons, sized by disk use.

  • Seed, size and version

    Read from the level data, not typed in.

  • Switch, rename, duplicate

    Change worlds without opening server.properties.

Backups

06 / 09

  • Manual or scheduled

    World saves paused while it runs.

  • Browse restore points

    Every backup, tagged and searchable.

  • Roll back in two clicks

    Restore with the server stopped.

Config editor

07 / 09

  • server.properties as a form

    Every setting under a readable name.

  • Raw mode

    The file itself, syntax highlighted.

  • YAML, JSON and TOML

    Plugin and mod configs open in the same place.

Mods and plugins

08 / 09

  • Install from Modrinth

    Search, pick a version, it lands in the right folder.

  • Dependencies resolve

    What a plugin needs comes along with it.

  • Changelogs inline

    See what a version changed before you take it.

Multi-server

09 / 09

  • Every server in one app

    Survival, creative, a test server: one list.

  • Own jar, folder and JVM args

    Each server keeps its launch settings.

  • Switch with one click

    The whole dashboard follows the server you pick.

02

Scheduler

Trigger Daily at 04:00
Condition Players online = 0
Action Back up world
Action Notify

Triggers

A time, an interval, or something the server did.

Attributes

Read live server values, and write settings back.

Conditions

Compare values and branch. Failures get their own path.

Actions

Commands, backups, delays, notifications, webhooks.

03

Local-first

No telemetry

No analytics, no crash reports. Nothing phones home.

Stays on disk

Settings as JSON on your disk. Backups where you point them.

Network on request

GitHub, Modrinth, and your own server over RCON.
