[i] about

Everything you'd do over SSH, in one window

Konnekt is a desktop control panel for self-hosted Minecraft servers. Starting them, watching logs, moving worlds, scheduling backups, installing mods: the work you'd otherwise do through a raw console, RCON or SSH.

Built for admins and hobbyists who run their own servers and want a real GUI instead of a stack of terminal windows and plugins.

Servers
Vanilla, Paper, Spigot and Bukkit, plus modded Fabric and Forge.
Platforms
Windows and Linux builds. macOS from source.
Status
Alpha. Console, scheduler, worlds, backups and mods work today.

() scheduler

Automate with a graph, not cron

Wire triggers, conditions and commands on a canvas.

  • Triggers

    A time of day, a cron line, an interval, or a server event.

  • Branching

    Every action forks into a success and a failure path.

  • Live values

    Read TPS, player count and other server state as it runs.

  • On demand

    Run a graph yourself, or leave it to the schedule.

[#] local-first

Your server, your machine

A desktop app, not a hosted panel. No account, nothing to sign up for.

⊘

No telemetry

  • No analytics or usage tracking
  • No crash reporting
  • Nothing phones home on launch
▤

Stays on disk

  • Your server directories, where they already are
  • Settings and layouts as JSON in the app data folder
  • Backups written wherever you point them
⇄

Network, only on request

  • GitHub, to check for a new release
  • Modrinth, while you browse or install mods
  • Your own server, over RCON
