[i] about

Everything in one window

Konnekt is a desktop app for Minecraft servers you host yourself. One window in place of a terminal, an RCON client and a file browser sitting open side by side.

Konnekt runs on your own machine, against server folders you already have. The dashboard is a grid of tiles you arrange yourself, and the automation is a node graph rather than a cron line.

What's inside

The tools Konnekt gives you to run your servers.

  • Drag, resize and snap every tile

    Pick a tile up by its title bar and the rest of the grid makes room.

  • Crate the ones you are not using

    Close a tile and it waits in the sidebar until you want it back.

  • Save and switch layout presets

    Console focus, compact, essentials, or your own, one click apart.

  • Live log streaming

    Every line the server prints, as it prints it, with Konnekt's own narration boxed.

  • Send commands inline

    Type at the prompt and the reply lands in the same stream.

  • Filter and search output

    Narrow the scrollback to one kind of line, or to a word.

  • See who is online

    A card per player, lit while they are on.

  • Kick or ban with a reason

    The reason goes with the command, and the roster follows when they go.

  • Op, whitelist and ban state

    Each player's standing, in one panel.

  • Live TPS, CPU and memory

    Read straight off the process and the tick, nothing installed on the server.

  • An hour of charted history

    A sample every ten seconds, kept for an hour, so a dip has a shape.

  • No plugins to install

    Konnekt watches the process it started; the server never knows.

  • Each world as its own planet

    Its nether and end as moons, sized by what they take on disk.

  • Seed, size and version

    Read from the level data, not typed in.

  • Switch, rename or duplicate

    Change the active world without opening server.properties.

  • Manual or scheduled

    Back up now, or let a schedule do it with world saves paused.

  • Browse restore points

    A carousel of every backup, tagged and searchable.

  • Roll back in two clicks

    Restore with the server stopped, and that backup is the world.

  • server.properties as a form

    Every setting under a name you can read, not a key you have to know.

  • Syntax-highlighted raw mode

    The file itself, in an editor, when the form is not enough.

  • YAML, JSON and TOML aware

    Plugin and mod configs open in the same place.

  • Install from Modrinth

    Search, pick a version, and it lands in the right folder.

  • Dependencies resolve automatically

    What a plugin needs comes along with it.

  • Changelogs read inline

    See what a version changed before you take it.

  • All your servers in one app

    Survival, creative, a test server: one list in the sidebar.

  • Own jar, folder and JVM args

    Each server keeps its own launch settings.

  • Switch with one click

    The whole dashboard follows the server you pick.

Automate with a graph

Wire triggers, conditions and commands on a canvas.

  • Triggers

    A time, an interval, or something the server did.

  • Attributes

    Read live server values, and write settings back.

  • Actions

    Commands, backups, delays, notifications, webhooks.

  • Conditions

    Compare values and branch. Failures get their own path.

[#] local-first

Your server, your machine

A desktop app, not a hosted panel. No account, nothing to sign up for.

⊘

No telemetry

  • No analytics or usage tracking
  • No crash reporting
  • Nothing phones home on launch
▤

Stays on disk

  • Your server folders, untouched
  • Settings as JSON on your disk
  • Backups where you point them
⇄

Network, only on request

  • GitHub, to check for updates
  • Modrinth, when you browse mods
  • Your own server, over RCON
