Where it's going

What's shipped, what's next, and what won't be built.

Alpha Beta Full release Later Out of scope

Alpha Complete

In daily use. Everything below ships in the current build.

  • Multi-server management. Any number of instances, each with its own jar, JVM arguments and working directory, plus a guided EULA flow. Start, stop and restart any of them.
  • Live console. Log streaming, inline commands, colour-coded output, custom quick-commands.
  • Stats. TPS, RAM and CPU, with an hour of history charted.
  • Player list. Who's online, with kick and ban.
  • Node-graph scheduler. Triggers, conditions and actions on a canvas, with branching and live server values.
  • World management. Switch the active world, inspect size, seed and type, jump between dimensions.
  • Backups. Manual and scheduled, with a visual restore carousel.
  • Config editor. server.properties as a form or raw text, JSON and YAML aware.
  • Mods and plugins. Modrinth search and install, with dependency resolution, loader detection and inline changelogs.
  • Tile dashboard. Drag, resize, snap, crate unused tiles, save layout presets.
  • Notifications and an in-app updater.

Beta In progress

Tracked as GitHub issues labelled milestone:beta.

  • Server switching. The worlds and mods tiles follow the active server; the console, scheduler and status tiles do not yet.
  • Backups, hardened. Per-world backups in the Worlds tile, multi-dimension coverage, retention and pruning, cancel-in-progress, a concurrency guard, restore integrity checks, import from an external file.
  • New tiles. File explorer, audit log, a fuller mod manager (Modrinth plus CurseForge), player profiles, skin previews.
  • Config editor. Grouped fields, a gamerule editor, MOTD preview.
  • Extended history. 24-hour and 7-day performance windows.
  • Public server IP via a playit.gg tunnel.
  • Configurable shortcuts, plus global JVM defaults and a backup retention policy.
  • Additional alpha issues found in daily use, fixed as they surface.

Full release Planned

Everything above, finished, plus the release work an alpha skips. Beta lands first.

  • No known data-loss bugs. Automated coverage on the paths that touch your server files: backups, restores, world switching, config writes.
  • Published macOS builds. macOS builds from source today; a full release ships it alongside Windows and Linux.
  • Installers and packages. A Windows installer and a Debian package, rather than a bare executable next to the existing .rpm.
  • Signed builds. Signed on Windows, notarised on macOS, so a first launch doesn't trip an OS warning.
  • Stable on-disk state. Versioned config with migrations, so servers, layouts, presets and scheduled tasks survive every update.
  • Docs for every tile. The current docs cover getting started and little else.

Later Not scheduled

  • Remote access. The full dashboard over the web, for servers on another machine. Konnekt is a local-first desktop app today.

Explicitly out of scope Won't build

  • Bedrock Edition. Different command syntax; it would be a second product.
  • Minecraft versions before 1.20.5.
  • Accounts, tiers and subscriptions.
