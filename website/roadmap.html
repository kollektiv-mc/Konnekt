Where it's going

What's shipped, what's being worked on, and — just as usefully — what is deliberately never going to be built.

Alpha Beta Later Out of scope

Alpha Complete

The alpha scope is finished and in daily use. Everything below ships in the current build.

  • Multi-server management — any number of instances, each with its own jar, JVM arguments and working directory; independent start, stop and restart, with a guided EULA flow for first-time setup.
  • Live console — real-time log streaming, inline commands, colour-coded output, and custom quick-command buttons.
  • Real-time stats and history — TPS, RAM and CPU, with an hour of performance history charted.
  • Player list — who's online, with kick and ban.
  • Node-graph scheduler — triggers, conditions and actions wired on a canvas, with branching and live server values.
  • World management — switch the active world, inspect size, seed and type, jump between dimensions.
  • Backups — manual and scheduled, with a visual restore carousel.
  • Config editor — server.properties as a form or as raw text, JSON and YAML aware.
  • Mods and plugins — search and install from Modrinth with dependency resolution, loader detection, and inline changelogs.
  • Tile dashboard — drag, resize, snap, crate unused tiles, and save layout presets.
  • Notifications and an in-app updater.

Beta In progress

Individual beta items are tracked as GitHub issues labelled milestone:beta.

  • Backups, hardened — per-world backups surfaced in the Worlds tile, multi-dimension coverage (nether and end), retention and pruning, cancel-in-progress, a concurrency guard, restore integrity checks, and import from an external file.
  • New tiles — file explorer, audit log, a fuller mod/plugin manager (Modrinth plus CurseForge), player profiles, and skin previews.
  • Config editor enhancements — grouped fields, a gamerule editor, and an MOTD preview.
  • Extended performance history — 24-hour and 7-day windows alongside the current hour.
  • Public server IP via a playit.gg tunnel, for exposing a home-hosted server without touching your router.
  • Configurable keyboard shortcuts, plus the remaining settings (global JVM defaults, backup retention policy).

Later Not scheduled

  • Remote access — the full dashboard over the web. Konnekt is a local-first desktop app today and manages servers on the machine it runs on. Reaching a server on another box, through a browser, is a substantial piece of work with its own security surface, so it sits behind beta rather than inside it.

Explicitly out of scope Won't build

Recorded so they don't get re-litigated:

  • Bedrock Edition. The command syntax is different enough that supporting it would mean a second product, not a compatibility flag.
  • Minecraft versions before 1.20.5. Nothing predating the component item format is supported.
  • Accounts, tiers and subscriptions. Removed with a previous codebase and not coming back. Konnekt is local-first and CC0; there is nothing to sell you.

Konnekt is a personal side project, built to run its author's own Minecraft servers rather than to match what a wider community might expect from it.
